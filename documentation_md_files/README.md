## ✍️ Rules for Future Updates

For every new update made to the project:
1. Create a new markdown file named sequentially: `07_<update_title>.md`, `08_<update_title>.md`, etc.
2. Structure the document with the following mandatory sections:
   - **Summary of Changes**
   - **What Was Added**
   - **What Was Removed / Refactored**
   - **What Happens as a Result**
   - **Technical Logic & Rationale**
3. Update this `README.md` index file.
